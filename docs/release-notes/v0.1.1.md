## Download

| | |
|---|---|
| **macOS** 14.6+, Apple silicon and Intel | `Das-Meter-0.1.1.dmg`: drag Das-Meter to Applications, then allow it once under **System Settings ▸ Privacy & Security ▸ Open Anyway**. |
| **Windows** 10 and 11, x64 | `Das-Meter-0.1.1-windows-x64-setup.exe`: run it. It installs the app and the Send Plugin (CLAP and VST3). |
| **Linux** x86_64, PipeWire | `das-meter-0.1.1-linux-x86_64.tar.gz`: unpack it and run `./das-meter`. |

Every step is in the [install guide](https://github.com/daswerk/Das-Meter/blob/main/INSTALL.md),
and every Meter is explained in the [docs](https://daswerk.github.io/Das-Meter/).

If you tried Beta 1: install this one by hand once. From here on,
**Check for Updates…** finds new versions by itself.

## New in this beta

- **Goniometer**: a new Meter, the scope of the old studio meters, with
  trails and a correlation bar.
- **A/B with System Capture**: while B plays, every other app goes quiet, so
  you hear the reference song alone.
- **Smoother Waveform**: no more flicker while it scrolls, and an option to
  boost quiet input.
- **Undo and Redo** (⌘Z / ⇧⌘Z, Ctrl on Windows) for Theme and Preset changes.
- **New built-in Presets and Themes**: Producing Top-Bar, Mixing/Producing
  (the standard Theme) and Mastering, all with thin lines and the same
  styling; colours that didn't fit their Theme are fixed.
- **Tonal Balance** shows only your songs' file names, and Learning asks for
  nothing more.
- Spectrum: the mouse readout is on by default.
- Settings: clearer sections, the colour buttons lined up.
- Help, Learn more and Check for Updates work.
- A new app icon.
