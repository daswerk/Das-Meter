# Updates and uninstall

## Updates

Das-Meter looks for a new version once a day (turn this off in the settings
with **Check for updates daily**). When there's one, a quiet note says so.

**macOS:** **Das-Meter ▸ Check for Updates…** looks now, and **Das-Meter ▸
Update to Das-Meter *version*…** installs it. Before installing, Das-Meter
checks that the download is signed with the release key built into the app,
and that the new app is signed with Das-Meter's certificate. It then replaces
itself and restarts. If Das-Meter can't write to its folder (for example
`/Applications` on an account without admin rights), it opens the release page
so you can update by hand. The Send Plugin is updated with the app; restart
your DAW when Das-Meter says so.

**Windows:** in the settings, **App** has **Check Now** and, when there's a
new version, **Update to Das-Meter *version*…**. Das-Meter downloads the
installer, checks it's signed with the release key built into the app, and
closes; Windows asks to allow the installer, which updates Das-Meter and the
Send Plugin and starts Das-Meter again. If a DAW has the Send Plugin open,
the new one takes its place when you next restart Windows. If you don't allow
the installer, Das-Meter starts again unchanged.

Your Presets, Themes and settings stay either way.

## Uninstall

**macOS:** choose **Das-Meter ▸ Uninstall Das-Meter…**. It moves the app and
the Send Plugins it installed to the Trash. Your Presets, Themes and settings
stay, unless you choose **Uninstall and Delete My Presets and Themes**.

**Windows:** use **Settings ▸ Apps ▸ Installed apps ▸ Das-Meter ▸
Uninstall**. It removes the app and the Send Plugin. Your Presets, Themes and
settings stay, unless you answer **Yes** to **Also delete my Presets and
Themes?**
