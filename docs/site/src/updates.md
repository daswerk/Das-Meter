# Updates and uninstall

## Updates

Das-Meter looks for a new version once a day (turn this off in the settings
with **Check for updates daily**), or when you choose **Das-Meter ▸ Check for
Updates…**. When there's one, a quiet note says so, and **Das-Meter ▸ Update to
Das-Meter *version*…** installs it.

Before installing, Das-Meter checks that the download is signed with the
release key built into the app, and that the new app is signed with Das-Meter's
certificate. It then replaces itself and restarts. Your Presets, Themes and
settings stay. If Das-Meter can't write to its folder (for example
`/Applications` on an account without admin rights), it opens the release page
so you can update by hand.

The Send Plugin is updated with the app; restart your DAW when Das-Meter says
so.

## Uninstall

**macOS:** choose **Das-Meter ▸ Uninstall Das-Meter…**. It moves the app and
the Send Plugins it installed to the Trash. Your Presets, Themes and settings
stay, unless you choose **Uninstall and Delete My Presets and Themes**.

**Windows:** use **Settings ▸ Apps**, like any other app.
